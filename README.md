# BASOKA (باسوکا) 🤖📱
### یاریدەدەری دەنگی و ژیریی دەستکردی کوردی بۆ کۆنتڕۆڵی مۆبایل
### Kurdish Sorani AI Voice Assistant & Phone Controller

**BASOKA** بەرنامەیەکی پێشکەوتووی ژیریی دەستکرد و یاریدەدەری کەسییە بۆ سیستەمی ئەندرۆید (Android)، کە بە زمانی **کوردیی سۆرانی** کاردەکات بە شێوەیەکی نەرم، دۆستانە و زانستی. ئەم ئەپە ڕێگەت پێدەدات بە دەنگ یان نووسین کۆنتڕۆڵی مۆبایلەکەت بکەیت، وەڵامی پرسیارەکانت بە بەڵگە و سەرچاوەوە لە گووگڵ دەربێنیت، وێنەی کەسایەتی و شوێنەکان بناسیتەوە، و بە تەواوی ئەرکەکانی ڕۆژانەت بەڕێوەببەیت.

---

## ✨ تایبەتمەندییە سەرەکییەکان (Core Features)

1. **کۆنتڕۆڵی ڕاستەوخۆی مۆبایل (Hardware & System Control):**
   - **فلایش (Flashlight / Torch):** هەڵکردن و کوژاندنەوە بە فەرمانی دەنگی (*«فلایش داگیرسێنە»*, *«فلایش بکوژێنەرەوە»*).
   - **دەنگ و ڕووناکی (Volume & Brightness):** کەم و زیادکردن و بێدەنگکردنی مۆبایل.
   - **وایفای و بلووتووس (Wi-Fi & Bluetooth):** کردنەوەی خێرای پەڕەی ڕێکخستنەکان بۆ هەڵکردن و کوژاندنەوە.
   - **کامێرا و وێنەگرتن:** کردنەوەی دەستبەجێی کامێرا بۆ وێنەگرتن.
   - **پەیوەندی و نامە (Calls & SMS):** تەلەفۆنکردن بۆ ناوەکان یان ژمارەکان لەگەڵ ناردنی نامەی کورتی تێکست.
   - **زەنگی کاتژمێر (Alarm & Reminder):** دانانی زەنگ بۆ کاتژمێری دیاریکراو.

2. **خزمەتگوزاری دەستپێگەیشتن و کۆنتڕۆڵی شاشە (Accessibility Service):**
   - خوێندنەوە و کورتکردنەوەی هەموو دەقێکی سەر شاشە بە زمانی کوردی.
   - سکرۆڵکردن (Scroll Up / Down)، کلیک لەسەر دوگمەکان بە دەق.
   - گەڕانەوە (Back)، چوونە سەر شاشەی سەرەکی (Home)، و نیشاندانی ئەپە کراوەکان (Recents).

3. **ناسینەوەی زیرەکی وێنە (AI Vision - Persons & Places):**
   - ناسینەوەی کەسایەتییەکان لەگەڵ پیشە، ژیاننامە و ئەکاونتە فەرمییەکانی تۆڕە کۆمەڵایەتییەکان.
   - ناسینەوەی شوێن و مۆنۆمێنتە مێژووییەکان لەگەڵ پۆوتانی دەقیقی جوگرافی (GPS) و دوگمەی کردنەوەی ڕاستەوخۆی نەخشەی گووگڵ (Google Maps).

4. **پشتڕاستکردنەوە بە بەڵگە و سەرچاوە (Google Search Grounding):**
   - بەستنەوەی وەڵامەکان بە ڕاستییە زانستییەکان و دابینکردنی بەستەری ڕاستەوخۆی سەرچاوەکان لە گووگڵ.

5. **دۆخی کلیل و بەکارهێنانی بێسنوور (Unlimited & API Key Settings):**
   - کارکردنی بێ کێشە و خۆکار بەبێ ئەوەی بەکارهێنەر ناچار بێت هیچ کلیلێک دابنێت.
   - خاوەنی بەشی تایبەت بۆ بەکارهێنانی کلیلی کەسی (Custom Gemini API Key) بە ئارەزووی خۆت.

## 🛠️ تەکنەلۆژیا و بیناسازی (Tech Stack)

- **زمان:** Kotlin
- **ڕووکاری بەکارهێنەر (UI):** Jetpack Compose (Material Design 3)
- **داتابەیس:** Room Database (بۆ پاراستنی مێژووی گفتوگۆکان بە شێوازی سەلامەت و خۆجێیی)
- **ژیریی دەستکرد:** Google Gemini API (gemini-3.5-flash / gemini-flash-latest) لەگەڵ Fallback Engine
- **دەنگ:** Android SpeechRecognizer & TextToSpeech
- **سیستەمی کۆنتڕۆڵ:** Android AccessibilityService & Camera2 API

## 🚀 چۆنیەتی داگرتن لەڕێگەی GitHub و کارپێکردن (How to Download & Run)

### شێوازی یەکەم: ناردن و بەستنەوە بە GitHub ڕاستەوخۆ لە AI Studio (Direct Push to GitHub)
1. لە بەشی سەرەوەی ڕاستی شاشەی **Google AI Studio**، کلیک لەسەر دوگمەی **Settings / Export** یان **Push to GitHub** بکە.
2. ئەکاونتی GitHub ـەکەت هەڵبژێرە و ناوی ڕیپۆزیتۆرییەکە دیاریبکە (بۆ نموونە `BASOKA`).
3. بە یەک کلیک هەموو کۆدەکان دەنێردرێنە سەر ئەکاونتەکەت لە GitHub! پاشان دەتوانیت لە ڕێگەی لاپەڕەی GitHub ـەکەتەوە کۆدی پڕۆژەکە داونلۆد بکەیت یان هاوبەشی پێبکەیت.

### شێوازی دووەم: داگرتن بە شێوەی ZIP (Download as ZIP)
1. لە لیستی سەرەوەی AI Studio، هەڵبژاردەی **Export as ZIP** یان **Download ZIP** هەڵبژێرە.
2. فۆڵدەری داگیراو لە کۆمپیوتەرەکەت دەربهێنە (Extract).
3. دەتوانیت ڕاستەوخۆ بخرێتە ناو ڕیپۆی نوێی گیت:
```bash
git init
git add .
git commit -m "Initial commit of BASOKA Kurdish AI Assistant"
git branch -M main
git remote add origin https://github.com/YOUR_USERNAME/basoka.git
git push -u origin main
```

### شێوازی سێیەم: داگرتن بە فەرمانی Git Clone
```bash
git clone https://github.com/YOUR_USERNAME/basoka.git
cd basoka
```

## 💻 کردنەوە لە Android Studio و دروستکردنی APK

1. نەرمەکاڵای **Android Studio** بکەرەوە.
2. هەڵبژاردەی **Open** دابگرە و فۆڵدەری `basoka` دیاریبکە.
3. چاوەڕێ بکە تا پڕۆسەی **Gradle Sync** تەواو دەبێت.
4. بۆ دروستکردنی فایلی APK، لە بەشی باڵای ئەندرۆید ستۆدیۆ بڕۆ بۆ:
   `Build` -> `Build Bundle(s) / APK(s)` -> `Build APK(s)`
   یان لە تێرمیناڵ ئەمە بنووسە:
   ```bash
   ./gradlew assembleDebug
   ```
5. فایلی بەرهەمهاتوو لەم شوێنە دەبێت:
   `app/build/outputs/apk/debug/app-debug.apk`
